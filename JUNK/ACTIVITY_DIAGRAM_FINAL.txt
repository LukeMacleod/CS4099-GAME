FIGURE CAPTION:

**Figure X: UML Activity Diagram for Gaelic Games Application**

This activity diagram models the user interaction flow of the Gaelic
Games educational application. Upon login, a decision node routes users
based on access code type: teacher codes (T-XX) direct to a monitoring
dashboard, while participant codes (P-XX) proceed through a sequence of
three games with intervening tutorials and intervals. Games 1 and 3
enforce time constraints ({duration ≤ 4 min} and {duration ≤ 3 min}
respectively). Game activities log session data to a Firestore database
(shown via data flow connections), which provides aggregated statistics
to the teacher dashboard. This diagram follows UML 2.5 notation while
abstracting implementation details for clarity.
