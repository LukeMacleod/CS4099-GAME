Accessibility statement

Last reviewed 16 October 2026. This site, and the game it describes, are being built against WCAG 2.2 AA. This statement says plainly where we believe we meet that today and where we know we do not yet.

Draft — to be re-checked by the Accessibility Specialist and HCI Lead before this is treated as a final, audited statement. No automated or manual accessibility audit has been run on this site yet; the claims below are design-time, not audit-verified.

This website

  • No JavaScript is required to read any page.
  • A "skip to content" link is present on every page.
  • Colour choices follow a 4.5:1 minimum contrast target for body text; our gold accent colour is used only for borders, badges and backgrounds behind dark text — never as text colour on a light background, because on its own it does not meet that ratio.
  • No content relies on colour alone; headings and structure use real HTML elements (<h1>–<h3>, lists, tables with headers), not styled paragraphs.
  • Layout is responsive and does not lock pinch-zoom.

Known gaps, from our own evaluation

The dissertation trial that this project is built on fed back real accessibility gaps directly, and we are stating them rather than quietly fixing them off-page: the trial teacher identified a need for dyslexia-friendly fonts, broader audio narration, and adaptive difficulty in the evaluated build (dissertation, p.66–67). None of those three are solved yet in the live game.

  • Dyslexia-friendly typography — not yet shipped in the game itself; this website uses a system font stack chosen for legibility, with a dyslexia-friendly typeface (Atkinson Hyperlegible, an open-licence font) planned once it is properly self-hosted rather than loaded from a third party at runtime.
  • Audio narration coverage — the current build has real recorded narration for its existing content, not yet extended across every planned addition.
  • Adaptive difficulty — not yet built.

Language accessibility

Every Gaelic string on this site is shown with its English alongside, and every Gaelic string is a draft awaiting review by a native Gaelic speaker before it is treated as correct — no automated system, including the one that helped build this site, is allowed to certify Gaelic as correct.

Tell us about a problem
